# Drum Kit 🥁

A classic interactive Drum Kit web application built with HTML, CSS, and JavaScript.

## Features

* Interactive drum pads (play using mouse clicks or keyboard keys)
* Visual button press animations and shadow effects.
* High-quality audio feedback for each drum instrument.
* Clean, responsive design with custom typography.

## Tech Stack

* HTML5 (Structure).
* CSS3 (Styling & Animations).
* JavaScript (DOM Manipulation & Event Listeners).

## How to Play

1. Clone the repository
2. Open `index.html` in your browser[cite: 2]
3. Click any drum button or press the corresponding keyboard key (`W`, `A`, `S`, `D`, `J`, `K`, `L`) to play sounds[cite: 2, 3]!
